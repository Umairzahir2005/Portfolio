# Umair Zahir Portfolio

A React + Next.js portfolio website built with Tailwind CSS, Framer Motion, GSAP, and Three.js.

## Project setup

1. Install Node.js (v18+ recommended) and npm.
2. Run `npm install` in the project directory.
3. Run `npm run dev` to start the development server.
4. Open `http://localhost:3000` in your browser.

## Features

- Next.js App Router
- Tailwind CSS styling
- Framer Motion animations
- GSAP scroll-triggered entrance effects
- Three.js hero scene with @react-three/fiber and @react-three/drei

## Notes

The current terminal environment does not have Node installed, so dependencies must be installed after Node is available.
